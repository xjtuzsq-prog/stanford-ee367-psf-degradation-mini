# 基于 PSF 的图像退化与频域分析

本项目灵感来源于斯坦福大学 EE367/CS448I：计算成像。

本项目旨在基于点扩散函数（PSF）构建一个小型计算成像实验。项目模拟使用高斯和散焦 PSF 的图像退化，分析频域中的图像模糊，并为后续复原实验做准备。

## 当前进展

- 高斯 PSF 图像退化
- 散焦 PSF 图像退化
- 频域分析
- 输出可视化
- MTF 曲线计算
- PSNR / SSIM 评估
- 维纳滤波
- Richardson-Lucy 复原
- 噪声水平与迭代次数比较

## 项目结构

- `images/`：输入图像
- `notebooks/`：Jupyter 笔记本
- `outputs/`：生成结果
